WhatsApp Business

Ingresa tus credenciales de WhatsApp Cloud API para conectar tu número.

📋 Guía paso a paso — WhatsApp Cloud API
⏳
Proceso de aprobación de Meta (2–4 semanas)
Antes de poder enviar mensajes a números que no son de prueba, Meta debe revisar y aprobar tu cuenta de Business Manager y tu app. Este proceso puede tomar entre 2 y 4 semanas. Mientras tanto, solo puedes enviar/recibir desde los números de prueba que Meta te asigna. Planifica con anticipación.
1
Crear app en Meta for Developers
Ve a developers.facebook.com/apps → Crear app → tipo Business → dale un nombre → click en WhatsApp en la lista de productos → Configurar.
2
Agregar número de teléfono
En el panel de WhatsApp → Configuración de la API → sección Desde → Agregar número de teléfono. Sigue las instrucciones para verificarlo con código SMS.
Después de agregar el número, copia el Phone Number ID que aparece en esa misma sección.
3
Generar token permanente
El token temporal dura 24 h. Para uno permanente: Ve a Configuración del sistema en tu Business Manager → Usuarios del sistema → crea un usuario → Agregar activos → selecciona tu app → activa permisos whatsapp_business_messaging y whatsapp_business_management → Generar token.
4
Configurar el Webhook
En WhatsApp → Configuración → Webhooks → Editar. Usa estos valores:
URL del webhook
Token de verificación
Después de guardar, activa el campo messages en la suscripción del webhook.
✓
Pegar credenciales abajo y guardar
Copia el Phone Number ID y el Token de acceso en los campos de abajo. Haz clic en Guardar conexiones. ¡Listo! Envíate un mensaje de WhatsApp para probar.
